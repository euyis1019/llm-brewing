LLM-Brewing General Prefill 八项正式实验

这些实验具体做了什么

这是一份按实验编号展开的方法与结论地图。每张实验卡片分别说明研究问题、实际操作、对照、关键结果、 能支持的结论和不能越过的边界。页面区分事前确定的验证实验与正式结果出来后追加的实验。

锚点模型：Qwen3-4B-Base · Qwen3.5-9B-Base 主运行：56cf303a0bee12f2__5ffa284ecd741a77 结果核验：2026-07-14

先看整条实验链

研究从数据审计开始，先确认答案信息何时可由外部读出、何时能被模型自己的输出路径读出， 再用受控标签变换排除表面模式。随后才进入状态替换、方向干预和组件敲除。

一、建立可信数据

冻结两条证据轨，确保目标 token、分组和两个模型的 tokenizer 身份可审计。

二、确认逐层现象

用外部线性探针和模型自身解码路径，分别定位信息可得性与信息就绪性。

三、检验因果作用

先做原定单层状态替换，再用多层窗口和方向引导查明负结果来自哪里。

四、定位承重组件

在接管边界附近敲除注意力和多层感知机输出，寻找局部承重结构。

两条证据轨

Track A 使用完整正确答案，负责通用领域广度和主确认性分析。

Track B 循环改变选项位置，负责控制答案绑定并构造因果实验配对。

三个逐层阶段

信息可得性表示答案可由外部线性探针读出。

信息就绪性表示模型自己的输出路径已经能稳定读出答案。

行为接管表示定向干预已经能稳定控制最终选择。

因果实验中的两个样本角色

来源样本提供答案定向状态或方向；被替换样本接受干预，并用于测量输出变化。

GP-DATA-01

冻结实验数据

数据前提 · 通过审计

先保证后续实验比较的是同一批语义问题、同一套答案身份和模型各自正确解析的目标 token。

研究问题

能否从九个公开 benchmark 构造两个模型都可比较、切分无泄漏、答案身份可追溯的冻结数据产品？

具体做法

  • 把不同数据源统一成规范记录。
  • 按语义身份去重并剔除冲突组。
  • 以规范问题组切分训练、验证和评测数据。
  • 隔离 few-shot 示例，避免与评测问题重叠。
  • 分别用两个模型的 tokenizer 编译正确答案。
  • 只保留完整答案在精确边界后为单 token 的样本。
冻结数据与正式评测范围
证据轨数据产品正式主评测用途
Track A 44,478 个样本，26 类完整答案 6,697 个样本，5,713 个规范问题组 主观测性结论与完整答案方向复现
Track B 26,750 个规范问题，107,000 个循环排列变体 4,044 个问题，16,176 个变体 受控标签变换和因果实验配对

得到什么

去重、分组隔离、目标 token 校验和训练评测组隔离均通过，为后续七项实验提供共同数据基础。

结论边界

GSM8K、MATH-500 和 CRUXEval 只代表完整答案满足单 token 条件的切片，不能代表这些 benchmark 的全部样本。

GP-OBS-01

观察答案何时可读、何时就绪

确认性通过

这项实验是主观测性结果：它比较外部线性探针何时能读出正确答案，以及模型自身输出路径何时能稳定读出同一答案。

两种读出

线性探针在每一层单独训练，负责定位信息可得性。

上下文剥离解码把该层状态直接接到模型最终归一化与输出头，负责定位信息就绪性。

确认性对照

  • 每种方法使用二十组完整空值运行。
  • 三个中性答案提示后缀。
  • 低秩探针和多层感知机探针容量消融。
  • 以规范问题组为单位进行两千次重采样。
  • 稳定起点要求连续至少三层超过确认性阈值。
Track A 双模型确认性结果
模型层数信息可得性起点 信息就绪性起点层位差不确定性区间
Qwen3-4B-Base36L18L224 层2 至 5 层
Qwen3.5-9B-Base32L13L196 层5 至 7 层

主要结论

两个被测模型中，正确答案都先变得可以由外部探针稳定读出，随后才变得可以由模型自身输出路径稳定解码。三个提示后缀下方向一致。

9B 模型的 L15 是直观例子：线性探针平衡准确率约为 0.57，而上下文剥离解码仍约为 0.20。

不能据此声称

这项实验是观测性读出实验。它不能单独证明主窗口内的状态已经能因果控制输出，也不能推广到所有语言模型。

GP-CF-01

改变正确答案的位置

确认性通过

保持题目和选项内容不变，只循环调整选项顺序，让正确答案对应的字母位置发生受控变化。

为什么要做

如果探针只是记住某些字母位置或题面模板，改变选项排列后，逐层读出就不应稳定跟随新的正确字母。

具体做法

每个规范问题生成四个循环排列；两个模型分别训练四类线性探针，并使用同口径的上下文剥离解码、空值对照和等变性分析。

Track B 选项置换反事实结果
模型层位差不确定性区间最终行为等变性探针等变性峰值
4B 模型1 层1 至 1 层0.7210.711
9B 模型3 层3 至 3 层0.8100.789

主要结论

改变正确答案的字母位置后，信息可得性仍早于信息就绪性，探针读出和最终行为也会跟随新的答案绑定。固定字母位置或单一题面模式不足以解释 Track A 的结果。

结论边界

读出能够跟随受控标签变化，不等于主窗口内的自然状态已经具有足够强的因果作用。

GP-CAUSAL-01

单层状态替换

确认性未通过

这是事前确定的因果验证实验。它直接检查：只替换主窗口中的某一层状态，是否足以把输出推向来源样本的答案。

具体操作

在 Track B 同一道题的不同选项排列之间，取来源样本某一层、观测边界处的残差流状态，替换被替换样本同层同位置的状态，然后继续运行模型。

实验对照

  • self 对照：重新注入被替换样本自己的状态。
  • 随机问题对照：改用其他问题的匹配来源状态。
  • 邻层对照：改用相邻来源层，检查层位特异性。
单层状态替换相对于随机问题对照的结果
模型Track A 主窗口窗口内平均效应首个稳定增强位置全层峰值
4B 模型L18 至 L22−0.690L24L34 为 5.9
9B 模型L13 至 L19−0.010L19 至 L20L31 为 10.0

正式判定

两个模型在主窗口内都没有达到“单层状态替换的答案定向效应超过随机问题对照”这一原定因果判据。因此状态保持为确认性未通过。

仍然有价值的观察

4B 模型的效应到 L24 才稳定增强；9B 模型在信息就绪性边界附近开始增强。这提示因果可用性晚于信息可得性，但它不改变原实验判定。

GP-AUDIT-01

审查结论能说到哪里

联合审计完成

这不是新的模型干预，而是把两个模型、两条证据轨、完整空值对照和原定因果检验放在一起，按事前确定的声明规则决定允许写出的最强结论。

通过的检查

  • 两个模型的主观测性层位差均为正。
  • 每种方法所需的二十组空值运行齐全。
  • 提示后缀敏感性检查方向一致。
  • 选项置换后，层间顺序和答案绑定仍然保留。

未通过或不允许的声明

  • 原定单层状态替换因果判据没有通过。
  • 不能声称主窗口内的因果机制已经闭合。
  • 不能把两个 Qwen Base 模型推广为所有语言模型。

最大允许结论

在两个被测 Qwen Base 模型和冻结数据范围内，规范正确答案在模型能够通过自身输出路径稳定解码之前，已经可以由外部线性探针读出。

产物：<run>/combined/claim_audit.json
GP-CAUSAL-02

多层状态替换与边界细扫

受控追加证据

单层替换可能被后续层重新计算覆盖。这项实验把来源样本的自然状态轨迹连续注入一个多层窗口，并逐层扩展窗口，观察何时开始稳定改变最终答案。

样本与设计

4B 模型使用 2,048 个配对、512 个选项置换组；9B 模型使用 1,024 个配对、256 个组。

同时设置窗口前、窗口后、self 和随机问题对照。

这项实验回答什么

一是检查原定实验的负结果能否只用“后层重算”解释；二是把行为接管开始出现的范围缩小到具体层位。

主要结论

覆盖整个主窗口的自然来源轨迹仍不能稳定接管输出，因此“单层干预被后层完全重算”不能单独解释原定实验的负结果。

4B 模型的行为接管边界位于 L24；9B 模型在 L19 已出现分数级效应，但行为接管要到 L22 才开始。分数变化与最终改判必须分开报告。

结论边界

这是累积窗口干预，只能定位接管发生在哪一段，不能证明边界层中的任意单个组件独自充分或必要。

GP-CAUSAL-03

沿答案方向推动隐藏状态

受控追加证据

不再复制自然状态，而是沿线性探针识别出的答案对比方向推动隐藏状态，用来区分“方向不对”和“方向正确但自然幅度不足”。

实验对照

  • 等范数随机方向：检查是否只是大幅扰动。
  • 负方向：检查答案语义是否呈反向变化。
  • 不同干预强度：观察效应是否随强度变化。
  • 单层与连续窗口：比较局部推动和累积推动。

运行范围

Track B 主运行中，4B 模型使用 1,024 个配对，9B 模型使用 512 个配对；之后又在 Track A 的 26 类完整答案空间中复现。

机制解释

主窗口中已经存在与答案对应的方向，但自然来源状态的幅度或下游读出连接还不足。到信息就绪性边界附近，方向特异的放大开始生效。这与“信息在场但欠放大”的解释一致。

不能据此声称

方向引导远强于自然波动。它能证明这个方向携带可被下游利用的信息，但不能证明模型自然运行时沿完全相同的方向、以相同幅度计算，也不能替代原定单层状态替换判据。

GP-CAUSAL-04

在每一层分别把观测位置的注意力输出或多层感知机输出置零，观察原本预测答案的分数、改判率和答案空间准确率如何变化。

把八项实验放在一起，结论是什么

确认性支持

  • 两个被测模型中，正确答案先达到信息可得性，随后达到信息就绪性。
  • 改变正确答案的字母位置后，这一层间顺序仍然保留。
  • 事前确定的单层状态替换没有达到原定因果判据。

受控追加支持

  • 自然来源轨迹覆盖整个主窗口时仍不足以稳定接管输出。
  • 答案方向的因果作用在信息就绪性边界附近增强。
  • 行为接管通常晚于最早的分数级效应。
  • 4B 模型的接管更集中，9B 模型更分布式。

当前机制解释

答案方向先进入一种外部可读、但自然幅度或下游连接还不足的状态。模型继续计算后，该方向逐渐被放大并接入自身输出路径，最终才具备稳定控制离散答案的能力。

仍然不能说

  • 不能说主窗口内的自然状态已经通过原定因果判据。
  • 不能把探针方向等同于模型的自然计算路径。
  • 不能把某个边界层宣布为对两个模型都充分且必要。
  • 不能推广到所有语言模型。

仍待回答的问题

  • 4B 模型 L24 注意力中，哪些头和上下文位置真正承重？
  • 9B 模型 L22 至 L25 的最小联合承重组件是什么？
  • 信息就绪性前后，答案方向的自然幅度如何逐层变化？
  • 相同边界规律能否在非 Qwen 模型上复现？
