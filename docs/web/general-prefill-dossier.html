术语速查

摘自 docs/glossary.md（权威术语规范，核验于 2026-07-14）。 下面只列本页会用到的词条；完整规范以原文为准。彩色圆点标出该术语属于哪个阶段。

读出、阶段与层位

信息可得性 information availability
正确答案可由外部线性探针稳定读出的状态。简称 availability。
信息就绪性 information readiness
正确答案可由 CSD 稳定读出的状态。简称 readiness。 用"可用性"翻译 readiness，会和因果可用性混淆。
因果可用性 causal usability
对中间状态做答案定向操纵后，模型读出或行为发生方向特异变化的状态。
上下文剥离解码 Context-Stripped Decoding, CSD
把某层状态直接接入模型最终归一化与输出头，绕开原始上下文计算路径来读答案。 把缩写展开成 context-independent self-decoding——那是语义解释，不是展开。
稳定起点 stable onset
轨迹连续达到确认性阈值的首层。本页取连续三层。单次偶然命中的层不算。
确认性 onset gap
readiness 起点晚于 availability 起点的层位差，用于 General Prefill 聚合确认性分析。
可得性到就绪性窗口
两个起点之间的层区间。引用时必须写明用的是 Track A 还是 Track B 的边界。 只写"gap 内"。
brewing gap
CUE-Bench 样本级诊断里，首次联合正确层与首次探针正确层之差。和本页的聚合 onset gap 是两个统计对象。

数据与观测边界

Track A GeneralPrefill-GT
完整答案 ground truth 证据轨，负责通用领域广度与主确认性分析。
Track B ChoicePermutation-CF
选项置换反事实证据轨，负责控制答案绑定与因果识别。
观测边界 observation boundary
prompt 最后一个 token 所在位置。缓存和主要干预都在这个位置读取逐层状态。
规范问题组 canonical question group
去重、切分隔离和 bootstrap 抽样的语义问题单位，可包含多个样本变体。本页所有 bootstrap 以它为抽样单位。
完整答案单 token 资格
完整规范答案在两个锚点 tokenizer 的精确 prompt 边界后都只对应一个 suffix token。数字和代码来源只代表满足该资格的条件切片。
残差流状态 residual-stream state
因果干预实际替换或修改的层间状态。只在确实操作残差流时使用，不是所有 hidden state 的泛称。
锚点模型 anchor model
完整跑通数据、探针、解码与因果分析的模型。双锚点设计指两个模型各自独立训练和缓存，最后做联合审计，不是跨模型共享探针。
空值运行 null run
破坏目标对应关系、但保留规定结构的对照运行。探针空值重新从头训练；CSD 空值只重配隐藏轨迹。 把随机基线泛称为 null。

因果实验

来源样本 / 被替换样本
来源样本提供答案定向状态或方向；被替换样本接受干预并被测量输出变化。
残差状态互换 residual-state interchange
把来源样本的残差流状态替换到被替换样本的对应位置。单层互换用于当前原定因果判据；窗口互换在连续层内逐层用来源样本轨迹钳制被替换样本。
探针方向引导 probe-direction steering
沿已训练探针给出的答案对比方向修改隐藏状态，强度按该层范数缩放。
四类对照
self：把被替换样本自己的状态重新注入，测注入操作本身的影响。随机问题：来源样本换成别的题，区分答案定向与一般扰动。随机方向：等范数随机向量，检验是否只是大幅扰动。负方向：反向干预，检验方向语义的反对称性。
logit 级效应
干预对来源样本与被替换样本答案分数对比的影响。引用时必须说明是否已减去匹配对照。
行为翻转率 flip rate
干预后答案空间预测切换到来源样本答案的比例。 跨不同答案空间横比翻转率（Track B 四选一与 Track A 两类读数不可直接比较）。
行为接管 behavioral takeover
干预开始稳定控制离散答案输出的现象。 用单个 logit 变化直接声称行为接管。
因果门槛 causal gate
预先规定的因果判据。当前"单层状态互换在可得性到就绪性窗口内超过匹配对照"这一门槛未通过。

实验编号速查

所有编号都以 GP 开头，表示属于 General Prefill 研究。 中间部分说明实验类型：DATA 是数据构建，OBS 是观测实验， CF 是受控反事实，CAUSAL 是因果干预， AUDIT 是结论审计。末尾序号只表示同类实验的登记顺序。

三个 gap 不是一回事

术语表里被单独列为禁止写法的头一条就是裸写 gap。本页涉及三个不同的统计对象： 确认性 onset gap（聚合层位差，本页主角）、 可得性到就绪性窗口（层区间，要注明 Track A 还是 Track B）、 brewing gap（CUE-Bench 样本级诊断量，本页不涉及）。

同理，因果结果有多个层位定义，所以没有"causal onset"这个词——只有 方向特异 logit 效应起点和行为接管起点，两者在 9B 上差了三层。

01

三个概念，三个不同的层位

整个扩展研究围绕一个区分展开：答案信息"在里面"和答案信息"能用"不是一回事。项目把它拆成三个可测的状态， 每个状态有各自的判据和各自的起点层。

最早出现
信息可得性 availability

正确答案能被一个外部线性探针稳定读出。探针是外挂的，读得出来不代表模型自己在用。

判据：逐层线性探针平衡准确率连续三层超过空值阈值
随后出现
信息就绪性 readiness

把上下文剥掉之后，模型用自己的解码路径就能读出答案。这一步不再借助外部探针。

判据：上下文剥离解码（CSD）的稳定起点
通常最晚
因果可用性 causal usability

对答案方向做定向干预，能稳定改变内部读出或最终输出。这里还要再分 logit 级效应和行为接管两档。

判据：干预效应超过匹配对照（随机问题 / 随机方向 / self）

readiness 起点减去 availability 起点，就是这项研究的核心量：确认性 onset gap。 两个起点之间的层段叫可得性到就绪性窗口。整份报告的问题都落在这个窗口里：答案已经在了，模型为什么还没开始用它。

03

数据：两条冻结证据轨

GP-DATA-01 的约束很苛刻：完整正确答案本身必须就是单个 next token， 而且两个锚点 tokenizer 都要能比较。九个公开 benchmark 过完这道筛子后分成两条轨。

Track A · GeneralPrefill-GT

完整答案 ground truth，负责通用领域广度和主确认性结论。九个来源，44,478 个样本，26 类答案；主评测用其中 6,697 个样本、5,713 个规范问题组。

Track B · ChoicePermutation-CF

选项置换反事实，负责答案绑定与因果识别。26,750 个规范四选一问题生成 107,000 个循环排列变体；主评测用 4,044 个问题、16,176 个变体。

结论边界

GSM8K、MATH-500 和 CRUXEval 的纳入率很低，因为只有答案短到能压进单 token 的题目才留得下来。 这三个来源只代表一个答案长度条件切片，不代表完整 benchmark，报告里也不拿它们做逐来源解释。

去重和分组隔离处理了几处真实的泄漏风险：MMLU ↔ MMLU-Redux 约 2.9k 条 prompt 重复， MMLU ↔ MMLU-Pro 约 6.5k 条共享问题，另外 BBH、C-Eval、CRUXEval 和 MATH-500 的 few-shot 池原本与评测行有重叠。 group_id 按规范化题面构造，保证同一道题的各种变体不会跨 split。

05

原定因果检验：没通过

GP-CAUSAL-01 · 确认性未通过

原定判据要求：在 Track A 主窗口内，把来源样本某一层观测边界处的残差流状态换给被替换样本， 产生的答案定向效应要超过匹配的随机问题对照。两个模型都没有通过。

这条状态被永久保留。后面三项追加实验无论结果多好，都不能把它改写成"已通过"。

GP-AUDIT-01 · 联合审计放行了什么

把两个模型、两条轨和原定因果检验结果合起来算，系统允许写出的最强结论是：

cross_model_gates.maximum_claim =
"gt_answers_linearly_decodable_before_context_independent_self_decoding"

universal_llm_claim_allowed = false

即：在两个被测 Qwen Base 模型和冻结数据范围内，规范正确答案在上下文独立自解码之前已经线性可读。 不能说所有语言模型都这样，也不能说因果机制已经闭合。

06

追加实验：把负结果拆开看

原定实验未通过之后有两种待检验的解释：一是后层重算——单层干预被后续层用未受扰的上下文覆盖掉了； 二是干预强度——方向是对的，但幅度不够。三项受控追加实验分别去掉这两条。

GP-CAUSAL-02 · 后层重算解释不成立

从 availability 起点开始，把窗口里每一层都用来源样本缓存轨迹钳制住，逐步延长窗口。如果是后层重算的问题，钳住整段应该就够了。

9B 这里出现一个必须分开记的现象：L13–L19 的相对随机问题效应已经转正（+1.09）， 但翻转率只有 7.8%，还贴着行为基线。logit 级效应和行为接管是两条不同的边界， 前者在 L19 接通，后者要等到 L22。

GP-CAUSAL-03 · 方向是对的，幅度不够

不换状态，改成沿已训练探针给出的来源样本/被替换样本对比方向去推隐藏状态，强度按该层范数缩放。 对照包括等范数随机方向和负方向。

4B 模型

  • L14–L19 相对随机方向效应不超过 0.7，随机方向自己也能造成很大扰动——这段没有清晰的方向特异性。
  • L20 效应升到 3.25，探针方向翻转率 56.9%，随机方向 9.1%。
  • L24 alpha=1 效应 6.44，翻转率 95.4%；L24–L30 的随机方向基本无效。
  • L25 alpha=2 正方向 shift +9.09，负方向 −5.19，反对称成立。

9B 模型

  • L10–L14 不具方向特异性。
  • 跨过 Track B readiness 起点 L16 后，L15–L17 逐步增强；L17 在 alpha=2 效应 3.27，翻转率 44.9%。
  • L19（Track A readiness 起点）alpha=2 翻转率 93.4%；L21、L23 在 alpha=4 到 100%。
  • L20 alpha=2 正方向 +7.52，负方向 −2.34；负方向把翻转率压到 0–3%。

窗口引导更清楚：9B 对 L13–L19 整段引导，alpha=1 翻转率 95.1%，探针方向 shift 8.47，随机方向 1.22，负方向 0%。 同样设置下最强的单层 L19 只有 53.3%。方向在窗口里就已经存在，多层累积能把它放大到足以改变行为。

这个模式在 Track A 的 26 类答案空间上复现了：4B 的 L24 边界再次出现（alpha=1 效应 8.01，翻转率 84.7%）， 9B 的 L19 升到 3.22、翻转率 46.1%，L25 在 alpha=2 到 99.2%。所以它不是选项置换设计的产物。

机制解释 · "在场但欠放大"

窗口里已经有一个可用的答案方向，探针能读出来，人为放大它也能改变行为——但自然状态自己的幅度不够， 或者下游还没接上这条读出。到 readiness 边界附近，方向特异的放大和读出才开始生效。

这是对多项结果的综合解释，不是原定判据。方向引导的幅度远高于自然波动， 它证明这个方向携带可被下游利用的信息，不证明模型自然运行时沿同一路径、以同样幅度计算。

07

能说什么，不能说什么

确认性结论

  1. 两个被测 Qwen Base 模型都显示 availability 早于 readiness。
  2. 该顺序在完整答案 ground truth 和选项置换反事实两条轨上都成立。
  3. 事前确定的单层状态互换在两个模型上都未达到原定因果判据。
  4. 结果不允许普适到所有语言模型。

受控追加证据

  1. 覆盖整个主窗口的自然状态互换仍弱，后层重算解释不了原定实验的负结果。
  2. 方向特异 logit 效应在 readiness 边界附近增强，行为接管通常更晚。
  3. 相同边界模式在 Track A 的 26 类答案空间复现。
  4. 4B 的接管结构更集中，9B 更分布式。

不能据此声称

  • 探针方向等同于模型的自然计算路径。
  • 累积窗口中的某个单层独自充分或必要。
  • 9B 没有中层机制——单组件敲除弱不构成证据。
  • 该边界规律适用于所有语言模型。
  • 可得性到就绪性窗口内的因果机制已经确认。

探索性观察

  • 9B 末端 MLP 敲除可能是校准或抑制效应。
  • 4B 部分方向引导曲线存在局部非单调。
  • 逐来源方向一致性只来自开发运行首看：CMMLU、MMLU、BBH、MMLU-Redux、C-Eval 五个较大知识类来源都出现正层差；MMLU-Pro 峰值约 0.5，深层后层差趋近零。尚未按来源分别建立确认性空值门槛。
